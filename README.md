# Registration Sniper

Registration Sniper is a timetable planner and registration companion for Sabancı University students.

It helps students:

- build a weekly timetable and spot overlapping sections;
- keep selected CRNs ready for registration;
- monitor seat availability and receive optional desktop or Telegram alerts;
- transfer prepared CRNs into recognized SUIS Add/Drop fields through the Chrome side panel.

## Availability

Access is provided through a Registration Sniper account. The application and extension share the same authenticated browser session.

The source code and production infrastructure are maintained privately. This repository contains public project information only.
