# Registration Sniper

Plan courses, monitor seat availability, and keep CRNs ready for Sabancı University registration.

## Features

- Build a weekly timetable and spot overlapping sections.
- Keep selected CRNs ready for registration.
- Monitor seat availability with optional desktop and Telegram alerts.
- Transfer prepared CRNs into recognized SUIS Add/Drop fields through the Chrome side panel.

## Get Registration Sniper

- [Open the web app](https://sabanci-registration-sniper.sitegap-tools.workers.dev/)
- [Install the Chrome extension](https://chromewebstore.google.com/detail/registration-sniper-%E2%80%94-crn/bheoacdoacbliaddomhdnaecepojhadn?authuser=0&hl=en)
